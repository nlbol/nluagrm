## ¿Qué es GNU/Linux?

GNU/Linux es un sistema operativo libre y de código abierto basado en el kernel Linux y las herramientas del proyecto GNU. Es utilizado en servidores, dispositivos móviles, supercomputadoras y computadoras de escritorio.

## Primeros pasos

### Elegir una distribución

Las distribuciones más recomendadas para empezar son:

- **Ubuntu**: La más popular, gran comunidad y soporte.
- **Linux Mint**: Similar a Windows, ideal para migrar.
- **Fedora**: Versiones actualizadas, patrocinada por Red Hat.

### Comandos básicos

```bash
ls          # Listar archivos
cd carpeta  # Cambiar de directorio
pwd         # Mostrar directorio actual
mkdir dir   # Crear directorio
rm archivo  # Eliminar archivo
```
